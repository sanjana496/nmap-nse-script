# My First Nmap NSE Script

A simple custom Nmap NSE script created for learning the basics of the Nmap Scripting Engine.

## Features

- Displays the target host IP address
- Uses the Nmap Scripting Engine
- Written in Lua
- Suitable for cybersecurity learning and authorized lab environments

## Usage

nmap --script ./myinfo.nse 127.0.0.1

## Purpose

This project demonstrates how a custom NSE script can be created and executed with Nmap.

## Disclaimer

Use this script only on systems that you own or have explicit permission to test.
